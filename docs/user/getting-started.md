# Getting Started

1. Pick a workspace folder on the welcome screen.
2. Configure a model provider in Settings > API Settings.
3. Use Start from template to open Assets, choose a safe reference, and insert it into the task draft.
4. Review the draft before sending. FishSwarm does not auto-run assets from the library.

Safety reminders:
- Keep secrets in provider settings or credential stores, not prompts.
- Review every file change request and approval prompt.
- Export packages require dry-run, no blockers, and human approval.
