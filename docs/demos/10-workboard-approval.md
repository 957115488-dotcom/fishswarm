# Workboard Approval

Goal: Create an Agent Workboard task linked to assets, roles, artifacts, and approval refs.

Steps:
1. Start from a clean workspace.
2. Perform the visible user action.
3. Capture the expected evidence.
4. Confirm no unsafe auto-run or secret exposure occurred.

Expected evidence:
- screenshot or screen recording when UI is involved;
- relevant artifact IDs or file paths;
- command/test output for developer demos.
